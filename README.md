# סוגרים

הצעת מחיר שנראית מקצועית, תוך שתי דקות. קובץ HTML אחד, בלי שרת ובלי התקנה.

**באוויר:** https://nativardi.github.io/sogrim/

## להשתמש אצלכם

- **בטלפון:** פותחים את הלינק ← "הוספה למסך הבית".
- **במחשב:** מורידים את `index.html` (או מהכפתור "הורדת סוגרים למחשב" בעמוד) ופותחים בדפדפן. עובד גם בלי אינטרנט (בלי חיבור יוצג פונט ברירת מחדל).
- **באתר שלכם:** מעלים את `index.html` לכל אחסון סטטי (GitHub Pages, Netlify, אחסון רגיל).

## לשנות

הכל בקובץ אחד:
- **צבעים:** המשתנים ב-`:root` בתחילת ה-CSS.
- **חלקים מהירים:** המערך `QUICK` בסקריפט.
- **ההצעה לדוגמה:** האובייקט `EXAMPLE`.
- **מונה שימוש אנונימי:** `COUNTER` בסקריפט. למחוק את השורה כדי לכבות.

הנתונים שממלאים נשמרים רק בדפדפן (localStorage) ולא נשלחים לשום מקום.
